# Passbase

> Passbase was a developer-first identity verification (KYC) platform: facial
> comparison, liveness detection, and government-ID authenticity checks across
> 190+ countries, delivered through client SDKs and a server-side Verifications
> API. Passbase was acquired by Parallel Markets in March 2023; api.passbase.com
> and docs.passbase.com are no longer live and this profile captures the
> last-published API surface. Backed by Cowboy Ventures and Seedcamp.

## API

- [Verifications API v2 (OpenAPI)](openapi/passbase-verification-openapi.yml): Read verified identities, their resources and resource files, and project settings. Base URL https://api.passbase.com/verification/v2 (historical). Auth via X-API-KEY.
